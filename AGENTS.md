# Repository Agent Instructions

- Before repository changes, inspect the relevant code and current `git status`;
  preserve unrelated user changes.
- After completing each engineering task, update [`CORE.md`](./CORE.md): refresh
  current state and open follow-ups, then add a concise dated entry under Recent
  engineering history. Record only validation actually performed.
- Never record credentials, tokens, private keys, or full environment values in
  `CORE.md`, `AGENTS.md`, or other documentation.
- Verify current source and live service state when historical notes may be stale.
