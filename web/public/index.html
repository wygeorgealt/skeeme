Calculus • Derivatives

Find the derivative of f(x) = x³ · ln(x) + 4x - 7 and determine critical points for x > 0.

📸 Solved via Camera OCR • 0.42s latency
1
Apply Product Rule: For u(x) = x³ and v(x) = ln(x), f'(x) = (3x² · ln(x)) + (x³ · 1/x) + 4
2
Simplify Algebraic Terms: f'(x) = 3x² · ln(x) + x² + 4 = x²(3 ln(x) + 1) + 4
3
Identify Critical Points: Set f'(x) = 0. Since x² ≥ 0 and 4 > 0, the function is strictly increasing for all positive real x.
